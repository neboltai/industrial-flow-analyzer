# Community and Industrial Editions

The Community Edition is a usable, tested deterministic engine for local analysis
of structured intralogistics data. The complete public engine is not deliberately
weakened. Calculations remain separate from AI interpretation.

| Community Edition (public, MIT) | Industrial Edition (commercial scope) |
| --- | --- |
| Complete deterministic engine and local CLI | WMS, ERP, MES, SQL and customer API connectors |
| Documented structured imports | Site-specific mapping and operating rules |
| Spaghetti diagrams and flow maps | Operational UI and approval workflows |
| Constraint-checked pair-swap simulation | Field validation and integration projects |
| Schemas, tests, evals and fictional examples | Audit trail, monitoring, backups and SLA |
| AI Skill and local demonstration MCP server | Remote HTTPS MCP service, authentication, authorization and tenant isolation |
| Community support without service commitment | Onboarding, maintenance and contracted support |

The right-hand column describes commercial integration scope, not a claim that
these services have already been implemented or certified. The CE CLI can process
real structured exports locally; the bundled MCP server intentionally exposes
only fictional data. Modelled distances and simulated improvements need field
validation before operational decisions.

The CE package is for local runtimes. It is not an approved public OpenAI listing.
A hosted OpenAI integration needs a stable, remotely reachable HTTPS MCP service
and the applicable review requirements. That deployment belongs to the hosted
Industrial offering; a local stdio manifest alone does not provide it.
