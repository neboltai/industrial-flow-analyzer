# Support

For reproducible defects, open a bug report at
https://github.com/neboltai/industrial-flow-analyzer/issues
using the repository's issue form. Include the
engine and Python versions, operating system, exact command, and a minimal
fictional dataset. Never attach customer exports, credentials or employee data.
For feature proposals, explain the decision the feature would support and how
it could be verified deterministically.

Community support has no response-time or availability commitment. For security
reports follow SECURITY.md rather than opening a public issue. Commercial
integration enquiries can start at https://nebolt.ai.

Before reporting a defect, install `.[dev,mcp]`, run `python scripts/check_release.py`
and retain the output. See EDITIONS.md for the commercial integration scope.
